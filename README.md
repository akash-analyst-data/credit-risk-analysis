# Credit Risk Analysis

## Objective
Analyze financial and customer data to identify patterns affecting credit risk.

## Tools Used
Python (Pandas, NumPy), Matplotlib, Seaborn

## Key Steps
- Data Cleaning
- Exploratory Data Analysis (EDA)
- Feature Analysis
- Risk Pattern Identification

## Key Insights
- Identified factors influencing credit risk
- Observed patterns in customer repayment behavior

## Business Impact
Helps financial institutions improve risk assessment and lending decisions.
